# CMU Serif

Computer Modern Unicode Serif (cm-unicode 0.7.0), the font the resume PDF is
printed in (the worker installs `fonts-cmu`). Served here so the editor's
live preview shows the same font on any machine.

Licensed under the SIL Open Font License 1.1 (`OFL.txt`). WOFF2 files from
the `computer-modern` npm package, version 0.1.3, unmodified. Original fonts:
https://cm-unicode.sourceforge.io/
